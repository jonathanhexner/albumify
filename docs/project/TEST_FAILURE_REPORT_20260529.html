3. HIGH — Face-pipeline embedding regression

Four tests from three files all assert face-recognition embedding quality against ground-truth pairs. They all fail in the same direction — measured similarity is far below the expected threshold. Most likely a single root cause (model alignment drift, normalization bug, or wrong model variant loaded).

TestFailureSuggested root cause
tests/test_face_pipeline_full.py::TestFullPipeline::test_pipeline_embeddings_match_ground_truth AssertionError: 15 faces have embeddings that don't match ground truth e.g. Face 557: similarity = 0.015 Face 558: similarity = -0.002 Embeddings should round-trip via cosine-sim ≈ 1.0 against same-face ground-truth embeddings. Near-zero indicates either: wrong embedding model loaded, embedding written to npy with wrong dtype/shape, or L2 normalization missing.
