OcclusionPenaltyComputer / OcclusionPenaltyConfigsim_bench/pipeline/scoring/occlusion_penalty.pyspec-097 third composite component in select_best (spec-084 pattern): 0 unless P(occluded) ≥ gate (0.8 ≈ 86% precision); then weight·P·area_factor(tiles), floored at −0.5. Bokeh-safe: driver is the learned P, never raw blur.
TiltScorer / TiltInputs / TiltScoreResultsim_bench/quality_assessment/tilt_geocalib.pyspec-099/spec-100 learned crooked-photo detector: GeoCalib single-image roll (validated spec-100; MAE 0.25–0.45° when confident, abstains honestly on structureless scenes). calc(inputs) → result per spec-053; score_tilt step caches per image, model_name="geocalib", version="geocalib_v1".
TiltPenaltyComputer / TiltPenaltyConfigsim_bench/pipeline/scoring/tilt_penalty.pyspec-099/101(A) fourth composite component in select_best, scaled by fixability: 0 unless confident+tilted; then −min(fov_weight·(1−retained_area), cap) if the crop cleanly straightens (small FOV cost), else −min(slope·(|roll|−gate_deg), cap=0.15) if UNFIXABLE (crop would clip a prominent person / drop below area floor). Reuses straighten_gate.decide so score and pixel fix agree.
straighten / largest_inscribed_rect / aspect_preserving_rectsim_bench/quality_assessment/straighten.pyspec-101 roll correction: rotate by −roll then crop to the largest inscribed rectangle (max-area or aspect-preserving closed forms) — no black/smeared border pixels ever. retained_area_fraction = the FOV cost.
GateConfig / GateResult / decidesim_bench/quality_assessment/straighten_gate.pyspec-101 subject-aware straighten decision (pure geometry): straighten iff confident+tilted AND crop keeps ≥ min_retained_area AND does not clip any YOLO person box ≥ prominent_person_frac of the frame; else decline. No saliency — reuses detect_persons.
StraightenImagesStepsim_bench/pipeline/steps/straighten_images.pyspec-101 (option A) TERMINAL step (depends_on select_best, runs last): straightens the selected winners that pass the gate, writes a leveled JPEG to the image cache, and repoints that entry in context.selected_images. Runs terminal so nothing depends on it — keeps the heavy tilt machinery from being dragged into other pipelines by the dependency resolver. straightened_from = provenance. enabled:false = penalize-only.

5b · ORM models — per-run face_clustering.db spec-058

SQLAlchemy DeclarativeBase models living under sim_bench/run_db/models/. The CREATE TABLE / CREATE INDEX strings in sim_bench/run_db/_schema.py are derived from Base.metadata at import time, not hand-authored — drift between models and the emitted SQL is caught by tests/face_clustering/db/test_orm_matches_schema.py (substitutes for alembic check; covers tables, indexes, columns, and foreign keys).

Two distinct Base classes live in the codebase and must never be merged (different lifecycles, different constraint-name namespaces): face_cluster/repositories/_orm_base.py targets the long-lived ~/.sim_bench/sim_bench.db with Alembic; sim_bench/run_db/models/_base.py targets the ephemeral per-run DB with no migrations (a new run = a fresh DB).
