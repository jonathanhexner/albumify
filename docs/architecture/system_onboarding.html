Key Design Decisions
  • Two separate pipelines: sim_bench/pipeline/ is a YAML-driven plugin system with topological sort. face_cluster/pipeline.py is a simpler fixed-sequence executor for standalone use.
  • Bridge pattern: cluster_people.py step delegates to face_cluster_bridge.py which converts between the two pipeline's data types.
  • App deep-link: Albumify exports artifacts to a run directory, then the FC app loads them via ?load_run=<path>.
  • UniversalCache: ML model outputs (embeddings, detections, IQA scores) are cached with mtime-based invalidation. Shared across pipeline runs.

StepDecision(
    item_id="D:/photos/IMG_001.jpg",      # image path or face key
    item_type="image",                     # "image" or "face"
    step="filter_quality",                  # which step decided
    decision="rejected",                    # "passed", "rejected", "selected", "detected"
    reason="IQA 0.08 < threshold 0.20",     # human-readable
    config_used={"min_iqa": 0.20},          # actual config used

)

Face Cluster Library face_cluster/

Standalone 8-stage pipeline for face identity clustering with conservative merge.

Pipeline Stages

STAGE 1
discover
Scan image directory
→
STAGE 2
embed
InsightFace SCRFD detection + ArcFace 512-dim embeddings
→
STAGE 3
quality
Blur/pose/area gating. Outputs: core vs holdout faces.
→
STAGE 4
crops
Save 112x112 aligned face crops
STAGE 5
cluster
Build kNN graph (K neighbors) → connected components
→
STAGE 6
exemplars
D10 scoring: select representative faces per cluster
→
STAGE 7
merge
Conservative 4-gate merge of cluster pairs
→
STAGE 8
export
Remap indices, write CSVs + face_clustering.db

Core Data Types

FaceRecord                           # One detected face
    face_id: int                      # Unique ID (0-based)
    image_path: str                  # Source image full path
    face_index: int                  # Index within that image (0, 1, 2...)
    bbox: Tuple[float, float, float, float]  # (x, y, w, h)
    embedding: np.ndarray            # 512-dim float32
    embedding_normalized: np.ndarray # L2-normalized
    pose: Tuple[float, float, float] # (yaw, pitch, roll) degrees
    blur_score: float                # Laplacian variance
    area: float                      # bbox area
    is_core: bool                    # Passed quality gating?
    quality_verdict: QualityVerdict  # Per-gate results
    det_score: float                 # Detection confidence
    d10_score: float                 # Exemplar selection score

ClusterResult                         # Output of clustering stage
    labels: np.ndarray               # Cluster label per face (-1 = noise)
    clusters: Dict[int, List[int]]   # cluster_id → face indices
    exemplars: Dict[int, List[int]]  # cluster_id → exemplar face indices
    cluster_stats: Dict[int, Dict]  # diameter, mean_dist, etc.
    n_clusters: int
    n_noise: int

Conservative Merge Algorithm (4 Gates)

Per iteration, the merger evaluates all candidate pairs where exemplar distance < threshold. Each candidate must pass 4 gates. Only the best (lowest exemplar distance) passing pair is merged per iteration.
GateCriterionPurpose
Exemplar/Crossexemplar_dist < threshold OR p25_cross_dist < cross_thresholdAt least one distance metric must be close enough
Supportcross-cluster pairs below threshold ≥ support_fracNot just one lucky pair — broad agreement
Margingap between best match and 2nd-best ≥ marginClear winner, not ambiguous
Diameterpost-merge diameter < expansion_factor × max(diam_a, diam_b)Merged cluster stays tight

Bridge: Main Pipeline ↔ Face Cluster Library

cluster_people.py → face_cluster_bridge.py → face_cluster/
The main pipeline's cluster_people step delegates to the standalone face_cluster library via a bridge module that:
  1. Converts PipelineContext face data into FaceRecord objects
  2. Builds a face_cluster.PipelineConfig (force-disabling quality gates already applied by main pipeline)
  3. Runs the face_cluster pipeline (stages: cluster → exemplars → merge)
  4. Returns (labels, face_records, base_cr, merged_cr, core_indices, merge_log, merge_metadata, fc_cfg)
Then face_cluster_export.py writes crops + CSVs + face_clustering.db for the standalone FC app.

Index Mapping (Critical Concept)

Graph-local vs Face-list indices
During clustering (stages 5-7), indices are graph-local (0..n_core-1) because only core faces enter the kNN graph. The core_indices array maps: graph_node_idx → face_list_idx. After the export stage, all indices are remapped to face-list indices for storage in the DB.

Deep-Link Integration
The Albumify main app exports artifacts to results/{album}/face_clustering_{timestamp}/ and the FC app loads them via URL parameter ?load_run=<path>. The exported directory contains: crops/, CSVs, merge logs, face_clustering.db, and pipeline_run.json.

Shared Config: ProfileStore

Both apps share configuration profiles stored at ~/.sim_bench/profiles/*.json. Streamlit widgets use rc_* keys (e.g., rc_K, rc_distance_threshold) so that profile loading/saving works identically in both apps.

# 1. Create and activate virtual environment
python -m venv .venv

Adding a New Pipeline Step

# sim_bench/pipeline/steps/my_new_step.py

from sim_bench.pipeline.base import BaseStep, StepMetadata
from sim_bench.pipeline.registry import register_step

@register_step
class MyNewStep(BaseStep):
    @property
    def metadata(self) -> StepMetadata:
        return StepMetadata(
            name="my_new_step",
            display_name="My New Step",
            description="Does something useful",
            category="analysis",
            requires={"image_paths"},   # context keys needed
            produces={"my_output"},     # context keys produced
        )

    def process(self, context, config):
        # Read from context, write to context
        for path in context.get_active_image_paths():
            # ... process image ...
            context.step_decisions.append(StepDecision(
                item_id=path, item_type="image",
                step="my_new_step", decision="passed",
                reason="Score above threshold",
            ))
