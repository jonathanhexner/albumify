Frontend Pages

Albumify main app — 7 pages, sidebar navigation, .streamlit/config.toml disables auto-nav

Configure & Run

pages/configure.py + components/pipeline_runner.py

Flat 3-column config grid (no expanders). ProfileStore shared with FC app (~/.sim_bench/profiles/). Run history table. Pipeline progress.

Results

pages/results.py

Metrics row. Deep-link card to FC app (fc_export_dir). Photo gallery with Detail buttons → image popup. Step timings.

People & Faces

pages/people_faces.py

Named/Unnamed/Needs Help/Flagged sections. Person detail with face bounding box on representative image. Merged People + Face Management.

Explore

pages/explore.py

6 tabs: Image Quality, Person Detection, Face Detection, Scene Clustering, Face Clustering, Selection. Shows StepDecision records with thumbnails. Paginated (20/page).

Export

pages/export_page.py

Export selected/all images. Organize by cluster/person. Copy/symlink/move modes.

Image Detail Popup

components/image_popup.py

@st.dialog triggered from any image. Shows: image with face bboxes, quality scores, filter/selection decisions, cluster info, per-face scores. Data preloaded (no API call).

Face Clustering App Integration

Main app exports artifacts → FC app loads via ?load_run=<path>

Export Flow (main app → disk)

cluster_people step saves base_cluster_result (deepcopy before merge)
_generate_crops_from_bboxes() creates 112x112 face JPEGs from source images + bboxes
export_results() writes faces.csv, clusters.csv using base clusters
export_merged_results() writes faces_merged.csv, clusters_merged.csv using merged clusters (when merges occurred)
merge_log.json serialized with _numpy_safe (floats, not strings)
fc_export_dir stored in PipelineResult for deep-link

Export Directory Contents

faces.csv
Base (pre-merge) cluster assignments
clusters.csv
Base cluster metadata + exemplars
faces_merged.csv
Post-merge assignments (if merges)
clusters_merged.csv
Post-merge cluster metadata
embeddings.npy
Float32 n×512 L2-normalized
crops/
112x112 face crop JPEGs
crop_manifest.json
face_id → crop path
merge_log.json
Per-pair merge decisions (float types)
pipeline_run.json
Config, summary, stages{merge:done}

Load Flow (FC app ← disk)

FC app reads ?load_run=<path> query param
load_pipeline_result(path) reads CSVs + embeddings → builds PipelineResult
Sets st.session_state.pipeline_result with output_dir = path
Tabs use _crop_for_face(face_id, result.output_dir) → reads crop_manifest.json → opens JPEG
Merge Analysis uses base cluster exemplars to show face thumbnails per merge pair

Cache Architecture

UniversalCache table — shared across runs, keyed by (image_path, feature_type, model_name)

FeatureCached?KeyRecompute Trigger
Face detectionsYes(path, insightface_detection, buffalo_l)Model change
Face embeddingsYes(path:face_N, face_embedding, model)Model change
IQA scoresYes(path, iqa, musiq)Model change
AVA scoresYes(path, ava, resnet50)Model change
Scene embeddingsYes(path, scene_embedding, dinov2)Model change
Quality filteringNo—Config thresholds change
Scene clusteringNo—Algorithm + params
Face clusteringNo—K, distance_threshold, merge params
SelectionNo—max_per_cluster, min_score

ProfileStore

~/.sim_bench/profiles/*.json — shared between main app and FC app. Same rc_* widget keys in both apps. Supports load/save/default profiles.
