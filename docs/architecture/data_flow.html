What this flow does NOT prove (today)

The diagram shows the path data can take. It does not show whether the upstream side of every contract actually produces the data the downstream side reads. That gap is exactly what SIGHTING-061 exposed: the bridge claims to plumb blur_score, but no upstream step computes it. Object-shape contracts can't catch this. The fix is the config-to-producer graph contract (specs/036) plus an E2E acceptance test (specs/035).
