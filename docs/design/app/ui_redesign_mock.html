Design Decisions (Google Photos-Inspired Redesign)

  • Navigation: Replaced sidebar with floating pill nav (5 tabs: Photos, People, Process, Results, Analysis). Album selector in top bar — always accessible.
  • Photos tab: Photo-first timeline with justified grid. People scroll row at top (circular avatars, like Google Photos). Filter chips for Selected/Rejected/By Person. Hover shows score + face count.
  • People tab: Face groups front and center. "Needs Help" section surfaces borderline faces with inline Yes/No/Skip decisions (no separate wizard page). Person detail inline with face grid + actions.
  • Process tab: Dedicated page for pipeline config (not buried in Results). Profile bar for shared presets (same ProfileStore as Face Clustering App). Config in a clean 2x2 grid — no nested expanders. All params visible at once.
  • Results tab: Dashboard with metrics row + run history table. Deep-link card to Face Clustering App is prominent. Selected photos gallery with filter chips.
  • Analysis tab: Embedded face clustering analysis (overview, merge decisions, cluster browser). Prominent link to standalone 11-tab app for deep analysis.
  • Key UX changes: (1) No nested expanders — all config visible in grid. (2) No page jumps — Process is its own page, not a tab inside Results. (3) People are first-class — visible from Photos and have their own page. (4) Async processing with step-by-step progress. (5) Run history shows all past runs with comparison.
  • Color scheme: Dark theme (#1a1a2e base, #16213e cards, #0f3460 inputs, #e94560 accent, #4ecca3 success). Designed for photo viewing (dark backgrounds make photos pop).
  • What stays the same: Backend API unchanged. Face clustering algorithm unchanged. Export functionality unchanged. Just the frontend navigation and layout.
