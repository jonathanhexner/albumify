2.Design — Frontend / Backend

FRONTEND app/face_clustering_v2/tabs/merged_clusters_tab.py (enrich; stays a thin orchestrator) summary strip (st.columns metrics) <- service.summary() filter + table (existing) <- service.list_merge_decisions(criteria) on row select -> detail panel: components/merge_gate_badges.py (✓/✗ per gate + value vs threshold) <- MergeDecisionRow components/cluster_pair_crops.py (two clusters' faces side by side) <- service.pair_faces(row) v BACKEND face_cluster/views/merged_clusters.py (extend MergedClustersService) .list_merge_decisions(criteria) [exists] -> MergeDecisionRow (already carries gate flags) .summary() [new] -> MergeReviewSummary (n_merged / n_rejected / top gate) .pair_faces(row) [new] -> PairFaces (cluster_a/b face_ids + crop paths) | reads only: | repo.get_merge_log() (rows) | repo.find_assignments(iteration=row.iteration) (faces of cluster_a / cluster_b pre-merge) | face_cluster.run_layout.crop_path (thumbnails) v REPO ClusterAnalysisRepository / RunStore — EXISTING, no new methods, no DB change.

Gate badges read fields already on MergeDecisionRow. The only genuinely new read is resolving each cluster's faces at the pair's iteration (pre-merge ids) — find_assignments already takes an iteration.

3.Data Contracts

MergeDecisionRow exists (spec-032/065) — listing the fields this tab reads. Two small new dataclasses.

# EXISTING — fields consumed (no change):
MergeDecisionRow:
  iteration, cluster_a, cluster_b, cluster_a_size, cluster_b_size,
  exemplar_dist, threshold_used, T_a, T_b, T_global,
  support, unique_support, required_support,
  post_diameter, max_allowed_diameter, margin_gap, margin_competitor_id,
  passes_cross, passes_exemplar, passes_support, passes_margin, passes_diameter,
  action, actually_merged, rejection_reason

# NEW
@dataclass(frozen=True, slots=True)
class GateBadge:
    name: str            # "cross" | "exemplar" | "support" | "margin" | "diameter"
    passed: bool
    detail: str          # e.g. "0.34 <= 0.38" / "gap 0.01 < 0.05"

@dataclass(frozen=True, slots=True)
class PairFaces:
    cluster_a: int; cluster_b: int
    a_face_ids: list[int]; b_face_ids: list[int]
    a_crops: list[str]; b_crops: list[str]     # absolute crop paths

@dataclass(frozen=True, slots=True)
class MergeReviewSummary:
    n_merged: int; n_rejected: int; top_rejection_gate: Optional[str]
