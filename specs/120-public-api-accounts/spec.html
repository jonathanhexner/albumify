spec-120 — Accounts and a public API: signed-in users upload a trip and get their album

Status: In Progress (W1 done 2026-11-22) · Created: 2026-11-22 · Roadmap: Stage C, next (productization plan steps 3-4) · Plan: productization plan · Continues: spec-106 (public service), spec-119 (repository slice)

Colour = type of change: NEW CHANGED REMOVED. Progress = ● done · ◐ partly done · ○ planned. In the class diagram: ✚ new member · ✎ changed · ✖ removed · unmarked = unchanged.

1. Objective

A signed-in user (invite only at launch) uploads up to 1,000 trip photos, the GPU curates them, and the album stays in their account until they delete it. A new small public API serves the coming Next.js website; today's FastAPI stays frozen for the owner's Streamlit app. Costs are capped per account and in total.

Decisions, risks, non-goals

  • Owner decisions 2026-11-22: invite list; 3 albums / 3,000 photos a month; $50 a month cap; 1,000 photos per upload; originals 7 days, albums until deleted; face consent + delete everything; US region; private albums; rename only.
  • Clerk for sign-in: it works natively with Next.js, has a free tier and Google + email-link built in; the API only verifies its tokens, so switching to Auth.js later touches auth.py alone.
  • Originals go to R2, staged on Modal's CPU. Resizing in the browser would cut a 4 GB upload to ~0.3 GB but needs a HEIC decoder in the browser; left to the website spec as an optimisation.
  • The public API is a second FastAPI app, not new routes on the old one: none of the old routes are reachable from the internet. The old API and Streamlit app keep working, frozen.
  • Risks: 3-5 GB uploads take 20-40 min at home speeds (the website warns, R6); Neon's free 0.5 GB fills at roughly 300 albums (today 89 MB for 59 runs), so watch it; Modal web endpoints cold-start in seconds.
  • Not in this spec: the website (next spec), payments, share links, editing beyond renaming, picking quality (after launch), the privacy-policy text (website spec; it states photos are never used for training).
