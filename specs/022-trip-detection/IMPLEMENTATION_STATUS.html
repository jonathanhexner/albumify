One sentence: A standalone, real-pipeline experiment groups Budapest photos by GPS and by time, scores which grouping is real (or declines), shows it on an interactive map, and now also runs three vision models per image — StreetCLIP (guess the city), GeoCLIP (guess lat/lon), BLIP (caption the scene) — so GPS-less photos still get a location and every photo gets a description; the remaining gap is the semantic axis + LLM theming that would turn those captions into named groups, and DB persistence / Albumify wiring.

New: a vision layer feeds the axes. Three models run per image, each disk-cached so re-runs are instant:
  • 📍 StreetCLIP — zero-shot pick of the most likely city from a fixed candidate list. The GPS fallback when EXIF has no location. streetclip.py
  • 🌐 GeoCLIP — regresses an actual (lat, lon) directly (no candidate list), then reverse-geocodes it offline to a place name. geoclip_locator.py
  • 📝 BLIP — free-text caption ("a group of people on a bridge"). Raw material for the future semantic axis. captioning.py
Still precise about SEMANTIC: captions exist, but the step from captions → themed, named groups (cluster the captions / ask a local LLM) is not built — the axis reads "insufficient." Identity (group by people) is similar: coded, but only activates when face clusters are supplied; the explorers don't feed them yet.

What you can run today (4 things)

1 · Album explorer — per-image CLIP/BLIP table DONE

Newest UI. Point it at a folder, hit Run, and it executes the real pipeline (discover → extract_geo_metadata → infer_geo_clip → caption_images → geo_temporal_segment) and shows a per-image table: EXIF time/GPS, StreetCLIP top-3 cities, BLIP caption, plus the home + segment summary.

.venv/Scripts/python -m uvicorn app.album_explorer.server:app --port 8078
# open http://127.0.0.1:8078 — type a folder, set a limit, click Run

First run downloads StreetCLIP (~600 MB) + BLIP (~1 GB); after that per-image results are disk-cached (~/.sim_bench/cache_streetclip.json, cache_blip.json, cache_geoclip.json). CPU inference — keep the limit small. Or run scripts/explore_geo_budapest.py for a static HTML report (BUDAPEST_EXPLORATION.html) covering all four signals incl. GeoCLIP.

2 · Geo explorer — live map + sliders DONE

Runs the real pipeline on a folder, then serves a Leaflet map (pins coloured by GPS cluster, auto home marker, click → thumbnail), a timeline (ticks coloured by time gap), live sliders (GPS radius / time gap / floor), and the live competition score table.

$env:GEO_EXPLORER_DIR = "D:/Budapest2025_Google"
.venv/Scripts/python -m uvicorn app.geo_explorer.server:app --port 8077
# open http://127.0.0.1:8077

Verified result: 122 photos · 44 with GPS · 84 with time · home auto-detected at 47.51, 19.05 (central Budapest). GPS spans only ~2 km, so geo makes 1 cluster and time wins; drop radius to 1 km to watch it split into 2 GPS clusters and the map recolour live.
