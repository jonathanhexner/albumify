End-to-end flow

GALLERY
  History "Load into analysis tabs"  ──▶  session.current_run_dir
  gallery_tab  ──▶  ClusterAnalysisService.list_clusters()        ┐ sync, sub-second
              ──▶  [per cluster] exemplar_face_ids(cid, 8)        │ (SIGHTING-079: no async)
              ──▶  cluster_strip(crops, run_dir)  ──▶  st.image ×8 │
  user clicks "Open"  ──▶  session.selected_cluster = 1  ──▶  st.rerun()
  user clicks Cluster Analysis tab  ──▶  cluster_picker defaults to cluster 1  ✓

OVERVIEW
  overview_tab  ──▶  OverviewService(RunHistoryRepository).compute_dashboard(limit=50)
               ──▶  DashboardMetrics
               ──▶  4-metric strip  +  render_bar(per_album)  +  render_bar(per_profile)
                                    +  render_timeseries(n_clusters over time)   [Plotly]
