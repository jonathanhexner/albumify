Who renders what

1
Tab header “Gallery” TAB
gallery_tab.render_gallery_tab() → st.header; resolves current_run_dir, else tab_skipped + info banner
2
Filter bar (min size, sort) TAB
inline in gallery_tab: st.slider + st.selectbox; filters/sorts the ClusterRow list in memory — no backend round-trip
3
Cluster row (id · size) COMP
components/cluster_strip.render_cluster_strip(row, run_dir) — one ClusterRow in, one row out
4
8 thumbnails COMP
cluster_strip → st.columns(8) + st.image(crop_path(...))
5
“Open in Cluster Analysis” COMP
cluster_strip → st.button → writes session_state['selected_cluster'] + st.rerun(). cluster_picker already defaults to that key ✓
6
Pagination (10/page) TAB
inline in gallery_tab: page index in session_state['v2_gallery_page']
7
Faces/cluster slider — G1 TAB
inline st.slider; feeds n into exemplar_face_ids(cid, n). Default 8, max “all”
G2
Clickable thumbnail → all fields COMP
cluster_strip per-thumb st.button("Open") → session_state['selected_face_id'] + st.rerun() → Face Analysis tab (reuses face_grid pattern; not a popup)
8
Quality FLAG badge — G5-flag COMP
cluster_strip renders ⚠ from FaceRow.is_outlier / low blur_score. Read-only — disqualify is spec-069
9
Nearest-outside strip — G4 (opt-in) SVC
toggle → compute_detail(cid).nearest_clusters → strip of nearest other cluster’s exemplars. ⚠ forces full compute (Decision D1, Option A cost)

23 Cluster list for filter + rows REUSE ClusterAnalysisService.list_clusters() () -> List[ClusterRow] out ClusterRow{cluster_id:int, size:int, diameter, n_exemplars, nearest_*} — noise excluded
4 8 exemplar thumbnails NEW (Decision D1) ClusterAnalysisService.exemplar_face_ids() — thin passthrough over repo (cluster_id:int, n:int=8) -> List[int] out face_ids, exemplars first. Needed because ClusterRow carries NO crop paths.
4 Each thumbnail image NEW (Decision D3) face_cluster…crops.crop_path() — shared helper (kills face_grid dup) (run_dir:Path, face_id:int) -> Path out run_dir/crops/face_{id:04d}_aligned.jpg; cluster_strip skips if missing
5 “Open” cross-tab nav REUSE none — pure session_state write; cluster_picker consumes it session_state['selected_cluster'] = cluster_id contract = the key name. cluster_picker defaults its selectbox to it (verified)
7 Faces/cluster slider — G1 REUSE ClusterAnalysisService.exemplar_face_ids() (same endpoint, variable n) (cluster_id, n) -> List[int] slider value = n; ClusterView.faces is the full sorted pool
G2 Thumbnail → all fields REUSE none here — writes key; Face Analysis tab calls FaceAnalysisService.compute_face_detail() session_state['selected_face_id'] = face_id downstream (face_id) -> FaceDetailView{blur, yaw, pitch, roll, area, bbox}
8 Quality FLAG badge — G5-flag REUSE none — reads fields already on FaceRow / ClusterView render ⚠ when is_outlier or blur_score < thr read-only. Mutation (disqualify) → specs/069-gallery-manual-disqualify
9 Nearest-outside strip — G4 (opt-in) NEW ClusterAnalysisService.compute_detail() (full ClusterView) (cluster_id) -> ClusterView out .nearest_clusters: List[NearestClusterRow{cluster_id, min_exemplar_dist, merge_candidate}]. ⚠ forces Option-A compute cost (Decision D1)
— Repository construction REUSE ClusterAnalysisRepository(ClusterAnalysisRepoConfig(run_dir)) (RepoConfig) -> Repository cached on session_state["_gallery_service::{run_dir}"]; st.error on failure
obs Telemetry REUSE _telemetry.tab_start/tab_done/component_render tab_done("gallery", n_clusters=15, page=1, thumbs_rendered=120) logger fc_app_v2.tabs; disable via FC_V2_TAB_TELEMETRY=0
