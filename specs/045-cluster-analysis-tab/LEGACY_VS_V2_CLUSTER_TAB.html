Cluster Analysis tab — Legacy vs spec-045 v2

Side-by-side: today's app/face_clustering/tabs/cluster_analysis_tab.py (383 LOC monolith) vs the spec-045 rebuild (Tab + Service + Repository, ~80 LOC tab).

PRESERVED same user-facing behavior SHAPED same intent, new code shape REMOVED anti-pattern dropped on purpose
Headline. The user sees the same workbench — cluster picker, metrics, face grid, nearest clusters, force-merge, graph debug. The code shape underneath collapses from one 383-LOC file that mixes Streamlit + SQL + JSON + async + business logic into a four-layer stack where each layer is independently testable and Streamlit-free below the tab itself.
