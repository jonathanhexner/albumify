3 · The architecture every new tab MUST follow

spec-045 (Cluster Analysis) established the canonical 4-layer split. Every new tab clones this shape — no exceptions. Architecture tests (extending tests/architecture/test_cluster_analysis_tab.py) enforce.

+---------------------------------------------------------+
|  TAB  (Streamlit only — orchestration)                  |
|  <tab_name>_tab.py ≤ 80 LOC                              |
|    - no SQL                                              |
|    - no FS reads                                         |
|    - no cfg.get("field", "?") literals                   |
|    - no AsyncHandle (use st.spinner — spec-079 lesson)   |
+---------------------------------------------------------+
                         |  typed dataclasses only
                         v
+---------------------------------------------------------+
|  COMPONENTS  (stateless render fns)                     |
|  components/<name>.py — each ≤ 100 LOC                   |
|  Consume typed inputs (ClusterRow, FaceRow, FaceView…)  |
+---------------------------------------------------------+
                         |
                         v
+---------------------------------------------------------+
|  SERVICE  (Streamlit-free)                              |
|  <name>Service in face_cluster/views/<name>.py            |
|    - sync methods returning typed dataclasses           |
|    - no st.session_state writes                          |
|    - composes Repository                                 |
+---------------------------------------------------------+
                         |  typed Criteria in / typed Rows out
                         v
+---------------------------------------------------------+
|  REPOSITORY  (B0b — query-shape)                        |
|  ClusterAnalysisRepository (existing — extended)         |

+---------------------------------------------------------+

        per-run face_clustering.db   +   embeddings.npy
        action_log (~/.sim_bench/sim_bench.db)
Pattern, not preference. spec-045 + spec-058/059 codified this stack. Every cross-cutting change this week (SIGHTING-078/079/080/089) was rooted in a layer skipping its contract. Architecture tests catch the pattern violation; the Budapest baseline catches the user-visible effect.
