NO sql / fs / cfg.get. v BACKEND face_cluster/views/excluded_faces.py (Streamlit-free, ~80 LOC) ExcludedFacesService(repo) .summary() -> ExcludedFacesSummary (funnel counts + per-gate) .list_excluded(c) -> list[ExcludedFace] | composes two sources: | #1 gate : repo.list_filter_decisions(rejected=True) [FilterDecisionRow] | #2 noise : repo.get_assignment_rows(include_noise=True) where cluster_id==NOISE_LABEL | crops : repo.get_face_records(face_ids) [FaceRecord.crop_path] v REPO sim_bench/db/face_clustering/cluster_analysis_repo.py (exists; read-only) per-run face_clustering.db (filter_decisions + cluster_assignments)

Mirrors the spec-063/064/065 split: thin tab → typed service → repository. The service is the only new logic; the tab is layout; the repo already exposes everything needed (no schema change).

3.Data Contracts

New typed objects (frozen dataclasses, like QualitySummary). GateCounts is reused from face_cluster.views.quality.

@dataclass(frozen=True, slots=True)
class ExcludedFace:
    face_id: int
    stage: str                 # "gate" | "unassigned"
    reason: str                # gate name (blur|pose|area|det_score) or "unassigned"
    measured: dict             # gate measurements; {} for unassigned
    crop_path: Optional[str]   # aligned-crop path for the thumbnail

@dataclass(frozen=True, slots=True)
class ExcludedFacesSummary:
    n_detected: int
    n_gate_rejected: int       # distinct faces with >=1 rejected filter_decision
    n_unassigned: int          # assignment rows where cluster_id == NOISE_LABEL
    n_assigned: int            # assignment rows in a real cluster
    gates: list[GateCounts]    # reused from quality.py (per-gate pass/reject)

    @property
    def pass_rate(self) -> float: ...
    def funnel_closes(self) -> bool:
        return self.n_gate_rejected + self.n_assigned + self.n_unassigned == self.n_detected

@dataclass
class ExcludedFacesCriteria:
    stage: Optional[str] = None   # "gate" | "unassigned" | None=all
    gate:  Optional[str] = None   # restrict to one gate name
Funnel invariant (the Phase-2 test's backbone): n_gate_rejected + n_assigned + n_unassigned == n_detected. If it ever fails, a face leaked between stages.
