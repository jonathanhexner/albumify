spec-113 — Remove the deprecated cluster_people step

Status: Implemented (2026-10-18) — owner approved scope + regression suite; O1–O3 per recommendations. Evidence: updates.md 2026-10-18 Owner: Jonathan / Claude Priority: P1 (dead code that already caused one silent quality bug: SIGHTING-132; no test pins Albumify's results) Relation: follows [[spec-079]] (replaced cluster_people with the 8-step chain); closes the clean-up left by SIGHTING-132.

1. Problem

spec-079 replaced ClusterPeopleStep with an 8-step people-clustering chain ending in assign_people_clusters. The old step stayed in the repo, registered and runnable. Three steps still named it as a dependency, so PipelineBuilder added it to every default run and it overwrote the new chain's people (SIGHTING-132, fixed 2026-10-16 by removing those three dependencies). As long as the step exists, it can come back the same way. Its name also survives as the settings key the UI uses for people clustering, which hides what actually runs.

3. Goal

  1. One people-clustering path in the code: the spec-079 chain. Nothing named cluster_people that can run.
  2. A regression suite that fails when the Albumify album on a real dataset drifts (R1). Nothing pinned it: the Budapest gate tests the face-clustering app, and the Albumify e2e test only checks "people non-empty", so SIGHTING-132 went unnoticed since spec-079.

4. Scope

  1. Delete the step, its config class, face_cluster_bridge.py, and the two unused yaml files.

  2. Rename the settings key cluster_people to people_clustering in pipeline.yaml, pipeline_service, the Albumify settings UI, and the face-clustering app.

  3. Fix explore.py to show the new chain's face decisions (quality_gate, attach_holdout_faces, ...).

  4. Tests: delete those that only test the old step; update the rest to the new key.

  5. Scripts: move the spec-079 investigation scripts to scripts/archive/ (see O3).

  6. Optional (O2): a named group people_clustering in a pipeline list that the builder expands into the 8 steps.

  7. Albumify regression suite (R1), section 7.

Out of scope: changing how the 8-step chain clusters.
