Per step vs CPU container: RAM++ 2.7x faster, YOLO 2.7x; InsightFace detect 1.3x, embeddings 1.0x; GeoCalib tilt 0.5x, occlusion CLIP 0.6x, DINOv2 0.7x (slower).
  • Root causes found by reading each step's device path:
    1. the GPU function had no cpu= request (default fractional core) -> every CPU-bound step starved;
    2. InsightFaceFaceAnalyzer hard-coded providers=['CPUExecutionProvider'] (device only changed ctx_id);
    3. the image installed both onnxruntime (via insightface) and onnxruntime-gpu; the CPU wheel shadows the CUDA provider;
    4. extract_scene_embedding dropped device when building the DINOv2 extractor;
    5. OcclusionScorer hard-coded clip.load(device="cpu"); 6. GeoCalib _get_model hard-coded .to("cpu").
  • Staged fixes (code edited, imports verified, NOT yet run on Modal): curate gets cpu=4.0; CUDA+CPU providers in face_analyzer.py (logs the active provider); image layer uninstalls both ORT wheels and installs onnxruntime-gpu==1.19.2 last, torch imported before ORT; DINOv2 device passthrough; OcclusionScorer(device=) + score_occlusion device knob; TiltScorer(device=) + score_tilt device knob. score_iqa is rule-based (no model) — nothing to move.
  • Next: re-run scripts/modal_curate_driver.py --start 300 --n 12 (GPU), confirm the InsightFace provider log says CUDA, compare per-step times; then AC4 idempotence; then storage-reference input.
