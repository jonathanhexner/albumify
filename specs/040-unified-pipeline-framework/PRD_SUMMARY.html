spec-040 — Unified Pipeline Framework

PRD summary · branch unification/spec-040 · 2026-05-21

Objective

Collapse three parallel face-clustering code paths (Albumify's cluster_people bridge, the legacy standalone FaceClusteringPipeline, and the partially-built unified steps) into one pipeline framework using a strangler-fig migration. Concretely:

  • One producer surface — context.face_records: List[FaceRecord] populated by the InsightFace producer chain, replacing the dict-of-dicts adapter.
  • One runner — FCAppRunner driving an 8-step registered chain (UNIFIED_CLUSTERING_STEPS) on PipelineExecutor.
  • One exporter — RunExporter writing schema v5 (adds images, scene_clusters, scene_cluster_assignments tables + ratio columns).
  • One new FC App at app/face_clustering_v2/ alongside the original during burn-in; legacy bridge + module emit DeprecationWarning, deleted in Phase 7.
  • Equivalence gate — pairwise cluster-assignment agreement ≥ 95% between legacy and v2 across a 4-config sweep on a 50-image fixture.

  • A — SRP-clean, fully testable, no hidden state, well-named. Safe to extend.

  • C — Procedural / multi-responsibility / bare excepts. Tolerable here because the module is scheduled for demotion or deletion.
  • D — Would block merge. (None in this PRD.)
