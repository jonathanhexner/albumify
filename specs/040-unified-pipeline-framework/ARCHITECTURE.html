3 · The five contract boundaries (target state)

BoundaryContractValidatorFails how
UI widget → step config dictPydantic per-step modelvalidate_step_config(step_name, dict) at BaseStep.processValidationError on typo / range
Step body → context objectPydantic FaceRecord / ImageRecord / SceneClusterRecordPydantic at construction; extra=forbid; field validatorsValidationError on unknown kwarg / partial pose
Pydantic object → DB rowPandera DataFrameSchemaRunExporter calls .validate(DataFrame) before INSERTSchemaError on NULL in non-nullable / out-of-range
DB row → Pydantic return typePydantic ImageDetail / FaceDetail / FaceFilterDecisionPydantic at construction (from SQL row dict)ValidationError on unexpected column
Gate config → upstream producerArchitecture test test_gate_has_producer.pyCI walks GATE_PRODUCERS + step produces_fieldsTest fails on PR if gate has no producer step

No bridge / adapter / translator class exists anywhere in this chain. The single translation hop is Pydantic → DataFrame → SQL row, with Pandera as the sole validator. Architecture test test_no_bridge.py + test_no_intermediate_face_dicts.py guard the constraint.
