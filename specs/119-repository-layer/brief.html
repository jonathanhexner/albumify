Layer 1 · CEO

In one minute

What it is. An internal clean-up of how our code talks to the database. Today about 60 places in the code write their own database queries. Spec-119 moves them all behind a small set of "repositories" (one class per kind of data, the only code allowed to query). Customers see no change.

Why it exists. Moving to the cloud database (Neon) on 2026-11-14 showed the cost of the scattered queries: most fixes touched several files, and one tangle between the GPU worker and the web server made a GPU run fail at start. The code review of that work (spec-117, finding M3) asked for this clean-up as a follow-up.

Recommendation. Do not build it before launch. The part the public site needs (fast reads that only show each user their own albums) is already built in spec-120. Commit the proposal and list it on the roadmap under "after launch".

How it relates to spec-120 and the launch plan overlap

Spec-120 built PublicAlbumRepo in a new package, sim_bench/public_api/. It follows the same rule spec-119 proposes (owner filter on every read, at most two queries each) but only for the public side. The owner's Streamlit app and its FastAPI keep the scattered queries; the plan freezes that API instead of fixing it.

The productization plan lists "retire the old API: move the owner app onto the public API's repositories" after launch. Spec-119 is the detailed version of that item, so the two should be merged into one post-launch row.

Layer 3 · App architect

Two rules come out of this spec. Only repositories write queries. And serving/, control/ and pipeline/ sit beneath the API and never import it. Both are enforced by architecture tests, so the layering cannot drift back.

Data model change: blobs to normalized rows W3–W4

RunPersister already writes image_metric_rows and face_metric_rows, but most reads still come from the PipelineResult JSON columns (scene_clusters, selected_images, image_metrics). After W3, reads use the rows. W4 backfills older runs that only have blobs. The blobs stay as a backup until the owner decides otherwise.
